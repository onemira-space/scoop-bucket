# OneMira Official Scoop Bucket

Official [Scoop](https://scoop.sh) bucket for **OneMira Desktop** — the local AI transcription, automatic speaker separation, Markdown Wiki, and CLI/MCP companion for the [OneMira C1 AI Voice Recorder](https://onemira.com/products/c1).

## Install

```powershell
scoop bucket add onemira https://github.com/onemira-space/scoop-bucket
scoop install onemira/onemira-desktop
```
